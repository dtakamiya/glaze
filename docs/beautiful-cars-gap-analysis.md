## 結論（要点）

現行 Glaze は工程の骨格・メニュー・コツの方向性は動画と一致している。ただし初心者が迷う点は、**「量」「判断」「禁止事項」「条件（水・天候）」が薄い**こと。コツが文字列の平坦なリスト（`tips`）で、「どの汚れに何番を使うか」「何 ml か」「何をしてはいけないか」が分からない。

## 1. 動画から確認できた BEAUTIFUL CARS 流の要点

- **砂を擦らない**が全ての中心。洗う前に流す、スポンジは離さず、1 パネルごとにスポンジを揉み洗いして面を替える。上→下、後ろ→前（Vo1JZJBJyiI, 8m1gxr-BR64, PzOYK006Vrg）。
- **シャンプー量**: 15L バケツに約 30ml（300 倍、水 9L 目安）。液 7 割・泡 3 割。泡を持ち上げない（WMdoBCCLTbI, MZ4FaD3w1gY, 8m1gxr-BR64）。
- **製品の番号ラダー**: 1 シャンプー（中性）→ 2 コロイドクレンザー（弱アルカリ）→ 3 インセクトリムーバー → 4 ミネラルリムーバー（酸性）→ 5 オイルステンリムーバー（溶剤）。**番号順に試す**。「飛ばすと取れない汚れが残る」（tkrrgBEwsj4, _Hmtub5Ru-g, 2bNaS8Uw8bs）。
- **仕上げ**: S1（ナノダイヤモンドトナー）はよく振って 1 プッシュ（ボンネット半分、約 1 m² が目安）。濡れた面に施工し、クロスを絞って拭き直す。S2（フルオリンセラム）は S1 の後に乾いたクロスで。S2 単独は不可（60RDq_TNnAU, tkrrgBEwsj4, R_vsy_UuaH0）。
- **水**: 水道水は乾く前に流す／拭く。純水なら乾いても跡が残りにくく、TDS メーターで 0 を確認。雨は水シミになりにくい（MZ4FaD3w1gY, Jq6bMNiRmTQ）。
- **炎天下（約 32℃）**: 洗う前に水をかけて冷やす。純水ならこの条件でも洗える。水道水は避ける（WMdoBCCLTbI）。
- **道具の使い分け**: クロスカットスポンジ（ボディ）、ソフトホイールスポンジ（半分に切る）、豚毛ブラシ（タイヤ）、100 円ショップのペットボトルブラシ（ホイール裏）、マイクロファイバー大（短毛で水拭き・長毛で仕上げ）と S（汚れ落とし）。タオルは 2〜3 回の洗車で交換（6RLoM6dwEkI, RWFhdoYEoBU）。

## 3. 動画とアプリの食い違い・要確認

1. **水シミ・水アカ除去の周期（28 日）は動画で確認できなかった**。動画では「正しい洗車（純水・乾く前に拭く）をしているとほぼ出番ない」（_Hmtub5Ru-g）、「水シミがなければこの作業はいらない」（2-eOM0fICdA）。日数で機械的に入れる現行の `MENU_CYCLES.mineral` は初心者に不要な手間を与える可能性がある。水シミタグ/水質条件と連動させる案を検討。
2. **フルオリンセラムの 28 日周期、コーティング補充の 14 日周期も根拠未確認**。動画で確認できたのは「S1 は洗車のたびに施工してよい」「持続は屋外で約 3 週間〜1 か月、3 週間に 1 回洗うのが目安」（60RDq_TNnAU）。アプリの `wipe-coat`（毎回）と `menu-coating`（14 日ごと）の役割分担を動画に合わせて見直す価値がある。
3. **4 番（ミネラルリムーバー）を濡れた面に使ってよいか**: tkrrgBEwsj4 は「濡れた場所でよい、薄まっても大丈夫」、2bNaS8Uw8bs は「濡れていると薄まるので水分を取ってから」。製品・用途で違う可能性がある。実装前に動画で確認。
4. **ホイール洗浄の周期（28 日）** は動画で確認できていない（`tire-wheel` の `everyDays`）。動画では毎回タイヤ・ホイールから洗う流れ（Vo1JZJBJyiI, R_vsy_UuaH0）。要確認。
5. 純水機の価格・値上げなどは宣伝性があり、アプリには入れない。

## 4. 既存の設計ルールとの整合

- 工程のコツ・NG・理由は `catalog.ts`（コード）に持つので、**保存スキーマの変更・移行は不要**。`StepTemplate` に任意フィールドを足すだけで済む。
- テンプレート ID は変更しない。新しい工程（準備など）は追加のみ。
- 状態タグは追加のみ。汚れ選択ヘルパー（#7）で新タグが必要なら追加で対応する。
- 条件チェック（#8）を保存する場合は v2 に任意項目として足すか、保存せず都度表示にする（公開後の追加は版を上げるルール）。
- 製品の注意（#3, #4）は `products.ts` の note 追加のみで、製品名は変更しない。

## 5. 推奨する進め方

1. **第 1 弾（P0 #1〜#6）**: `catalog.ts` / `products.ts` / `StepTip.tsx` の文面と `avoid`/`why` 表示。小さく安全で、初心者の事故（酸性剤の誤用、希釈ミス）を直接減らす。
2. **第 2 弾（#7, #8, #10）**: 洗車開始時の「準備＋条件＋汚れ」入口。
3. **周期の見直し（§3 の 1〜2）**: 動画を目視確認したうえで判断。
4. **追加分析**: 内装・鉄粉/タール・ポリッシュ・季節別の動画を追加で分析し、P2 を補完。

抽出元メモ: 作業用ディレクトリ（scratchpad）の `yt/out_A.md`〜`out_D.md`（動画ごとの 8 項目抽出）。

## A. 内装

動画で確認できたこと:
- 室内は**水拭き中心で洗剤はほぼ使わない**。水（純水が理想）で濡らして固く絞ったマイクロファイバーで拭く。水道水は乾いたタオルで仕上げ拭き（LPy7Rm9um5g, m8emlsG63ws）。
- 順序は「ほこりを飛ばす／掃除機 → 水拭き」。エアで飛ばしただけではほこりが戻るので拭き直す。エアや掃除機のホースを車体に当てない（m8emlsG63ws）。
- **内装用の艶出し剤は使わない**（ベタつき・汚れを呼ぶ・劣化の原因）。**メラミンスポンジで強く擦らない**（白くなる）。**メーターパネルは触らない**（拭くなら年 1 回程度）。ハンドル上のパネルはゴシゴシ拭かない（LPy7Rm9um5g, m8emlsG63ws）。
- ハンドルのテカリは皮脂。積もる前に水拭き、必要なら薄めた洗剤を布に含ませて撫でる。力は入れない（LPy7Rm9um5g）。
- 内窓: タオル 3 枚で水拭き→伸ばす→空拭き、乾く前に、力を入れない、角の尖ったヘラは使わない（タオルを巻く）。タバコのヤニは水拭きを繰り返して落とす（rOp7AIIhK2k, dCfIlqygnz0, l13ZdAjbB44）。
- 頻度: 普段は掃除機＋たまに水拭き。本格的な室内清掃は「数か月に 1 回、年 2 回で十分」（dTzxpXXhbDw、要確認）。

アプリへの示唆:
- `interior`（内装清掃）の `tips` は現在**空**。上記を `tips` / `avoid` / `why` に入れる（P0 と同じ方式で低コスト）。
- 内窓のコツは P0 #5 で入れた `window` と重複するため、内装側では「内窓は窓ガラス清掃の手順で」と参照する形にする。
- 薄め液の数値（水 200ml・30〜40 倍・プッシュ数）は動画内で整合しないため**入れない**（要確認）。

## B. 鉄粉・タール・油汚れ

動画で確認できたこと:
- 鉄粉は**粘土（クレイバー）を使わない**（傷の原因）。**引っ張らない・力を入れない**。ミネラルリムーバーを塗って反応させ、撫でて取る。取れなければ洗剤を足して繰り返し、それでも取れないものは**追わず次回**。錆びていない鉄粉は取れない（OQK0dgsWPPU, BQTJG4voiiI, 62tk2YK4-kY）。
- ミネラルリムーバーは**塗装面の水気を取った状態**で施工し、**乾いて濃縮する前に拭き取る**。複数箇所は 1 か所ずつ（62tk2YK4-kY, I84XtqwQfSQ）。
- 落ちない順の目安: ミネラルリムーバー → オイルステインリムーバー → タール・ピッチ用（62tk2YK4-kY）。
- タール・ピッチ: **乾いた状態**で、砂を先に流してから、溶剤を染み込ませて**撫でる（ゴシゴシ禁止）**。面を変える（K8Kw3rHxAtg, ZVbnpNWn5ko, ZBLnYPSDMkQ）。
- オイルステインリムーバーは**ゴム・タイヤ・無塗装の黒い樹脂・ラッピングに付けない**（白くなる）。垂れたまま放置しない。通常のプラスチック製スプレーボトルは不可。ドアヒンジの必要なグリスも落ちる（ZBLnYPSDMkQ, QPo3CX9g2Jk）。
- ホイールの鉄粉: アシッドホイールクレンザーは黄色い鉄粉・普通のダストに有効、黒いポツポツには弱い。洗剤が乾く前に流す（I84XtqwQfSQ, zz_3__tXMig）。
- 頻度: 鉄粉・水シミまで落とす「クレンジング洗車」は**年 2〜3 回**（字幕「23回」は 2〜3 回と推定、要確認）。年 1 回でも綺麗にできる（OQK0dgsWPPU, BQTJG4voiiI, 62tk2YK4-kY）。

アプリへの示唆:
- **水シミ・水アカ除去（28 日）は動画の頻度より大幅に多い**。動画は年 2〜3 回が目安で、本編の指摘（正しい洗車ではほぼ出番がない）とも合致する。`MENU_CYCLES.mineral` を日数固定から、状態タグ（水シミ・鉄粉・タール）起点＋長い間隔の提案に変える案を優先して検討する。
- 鉄粉・タールには専用の工程がない（状態タグのみ）。任意工程「鉄粉・タール処理」（新規テンプレート。ID は追加のみ）を追加し、`suggestion.ts` で tar タグ → オイルステインリムーバー／タール用の案内を出す。
- 製品: 動画に「タールピッチリムーバー」が出るが、番号が「06 番」と字幕にあり、別動画の「6 番＝アシッドホイールクレンザー」と食い違う。**製品名と番号を公式で確認してから** `products.ts` に追加する（名前は追加のみ）。
- 前回の「4 番を濡れた面に使ってよいか」の食い違いは、新しい 2 本（62tk2YK4-kY, I84XtqwQfSQ）が「水気を取ってから」と述べている。**安全側として「水気を拭き取ってから使う」を既定にする**のが妥当（tkrrgBEwsj4 の「濡れていても可」は薄まる前提の例外として扱う）。

## C. 季節・天候

**花粉・黄砂**（pJuhbS3MdbA, qJMIOmBU_-8）
- 乾いた花粉は慌てなくてよい。**濡れたら早く洗う**（水だけかけて放置するとベタついて染みになる）。乾いた花粉・黄砂は濡らさずブロワー等で飛ばす。
- 花粉自体は硬くなく、傷の原因は一緒に付く**砂・黄砂**。砂が付いたまま拭かない。
- ベタつきは湯（約 40〜50℃、要確認）を含ませたマイクロファイバーに少量のインセクトリムーバーで撫でる。熱湯は不可。
- 花粉期はナノダイヤモンドトナー（＋フローリンセラム）で表面を保護すると付着が抑えられる。
- 熱処理（ヒートガンで約 80℃）や研磨は上級者向けで、初心者向けアプリには入れない。

**夏・炎天下**（cX47TG6B5LQ, 本編の WMdoBCCLTbI）
- 暑く晴れた日は洗剤が乾くので**流しながら**作業する。熱い日は虫汚れが固着しやすいので早めに。虫を長く放置すると取れにくくなる。
- ミストファンは純水限定の製品紹介（宣伝性あり）。アプリには入れず、「熱中症対策」程度の一言に留める。

**冬・雪・融雪剤**（wxnwbLvDqMU, JJfRHFT3tMA, aYwhaP9cakU, _u87NbSJPWM, s6st4rVdi8k ほか）
- 融雪剤は塩で、**水でほとんど落ちる**。下回り・マフラー周りまで流す。放置（1〜3 か月）は錆びの原因。
- 雪道を走った後は**なるべくすぐ**、スキーなどは行くたびに。目安は**月 1 回**、半月延びても 1.5〜2 か月までなら通常の洗車で綺麗になる（JJfRHFT3tMA）。
- 水道水で流して拭かずに置くと水シミ。純水なら乾いても残りにくい。高圧洗浄機は**横から当てる・近づけすぎない**。ラジエーター周りに近づけない。
- マフラーの中に酸性クリーナーを入れない。冬は塩と湿気で汚れが落ちやすい。
- 雪下ろし: 暖気で雪を緩めてから、ブラシを直接ボディに当てず、ヘラ側（プラスチック）は使わず、凍った部分を無理に擦らない（6TUZUnzf8Ss, Kaxg9Kld1ek。毛の硬さの判断は要確認）。
- 純水器にお湯を通す条件などは製品固有の話なのでアプリには入れない。

アプリへの示唆:
- 季節を**月で固定しない**（花粉・黄砂の時期は動画から確定できない）。代わりに洗車前の条件チェック（本編 P1 #8）に「花粉・黄砂」「雪道・融雪剤」「炎天下」「雨」を選択肢として入れ、選ぶとコツを出し分ける。
- 状態タグに「花粉」「融雪剤」を**追加**（追加のみ可）すれば、履歴・提案とも連動できる。融雪剤タグがあれば「雪道走行後は早めに」の提案が出せる。
- 洗車間隔: 動画は「月 1 回」「3 週間に 1 回が目安」で、現行の `reminder.ts`（目安 2〜3 週間、超過の猶予 8 日）と大きくは矛盾しない。冬は 1 か月半〜2 か月まで許容という発言があるため、冬は猶予を延ばす案は任意。
